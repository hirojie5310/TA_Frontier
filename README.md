# TA FRONTIER QUEST

繊維の仕事・製品・部署のつながりを、短時間で体験できるブラウザRPGです。

## ゲームの特徴

- 4つのクエストで繊維の可能性を学ぶ
- 獲得ポイントで商品と交換する
- 商品を装備して、その先にある部署や仕事を発見する
- 3つの部署を発見するとゲームクリア
- PC・スマートフォンの両方に対応

## 遊び方

`index.html` をブラウザで開くだけでプレーできます。ローカルサーバーを使う場合は、このフォルダーで次を実行してください。

```powershell
py -m http.server 8000
```

macOS / Linux では `python3 -m http.server 8000` を使えます。

その後 `http://localhost:8000` を開きます。

1. 冒険マップでクエストに答えてポイントを獲得
2. 商品市場でフロンティア製品と交換
3. 商品を装備して担当部署を発見
4. 3部署を発見するとクリア

画面上部のタブ、または数字キー `1`〜`4` で画面を切り替えられます。

## 構成

外部ライブラリやビルド作業は不要です。`index.html`、`style.css`、`game.js` の3ファイルで動作します。
